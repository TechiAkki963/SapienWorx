Senior Full Stack Engineer

Acme Corp location_on San Francisco, CA (Remote) schedule Posted 2 days ago

About the Role

We are looking for a highly skilled Senior Full Stack Engineer to join our core product team. You will be instrumental in architecting, building, and scaling our next-generation enterprise platform. You'll work closely with product managers, designers, and other engineers to deliver high-quality, impactful features.

The ideal candidate is passionate about clean code, performance, and user experience. You should be comfortable navigating both the frontend and backend, with a strong emphasis on modern JavaScript ecosystems.

Responsibilities

  • Design and implement scalable backend APIs using Node.js and PostgreSQL.
  • Build responsive, accessible, and performant frontend interfaces using React and TypeScript.
  • Collaborate on technical architecture and drive engineering best practices.
  • Mentor junior engineers and contribute to code reviews to maintain high quality.
  • Participate in agile ceremonies and contribute to product planning.

Tech Stack

React Node.js TypeScript PostgreSQL GraphQL AWS
