# Recruiter governed workspace — implementation and acceptance matrix

Baseline: `30f1b507758bbd539db44925d6a73136b94eb524` (fresh origin/main inspection, 11 October 2026).
Working branch: `codex/recruiter-governed-workspace`. Deployment is explicitly gated; no live mutation is part of this implementation.

## Authoritative decisions

The latest master prompt overrides earlier iterations in the six source files. Workspace contains Home, Jobs, Applications, Messages, Interviews and Referrals. Recruit Plus+ contains Talent, Offers and Analytics only. Profile contains My profile and Preferences. Usage is contextual. Candidate result presentation is card-only and excludes Application Source. Jobs uses selection, title, Job ID, status, applications, unique Views, Posted and actions; Health and Deadline remain outside the primary list. Focused actions use centered dialogs and complex workflows dedicated pages.

Existing APIs, privacy rules, candidate data and company boundaries are preserved unless the matrix identifies a verified contract defect. Monetary calculations must be deterministic and server-authoritative. Published templates and approved/sent offer content are immutable snapshots. No new external services or AWS resources.
